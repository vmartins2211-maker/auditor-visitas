# Auditor de Visitas · versión web

Archivos que deben estar en el repositorio de GitHub:
app.py, procesar_visitas.py, requirements.txt, .gitignore y .streamlit/config.toml

Publicar en Streamlit Community Cloud (gratuito):
1. Crea un repositorio en GitHub y sube estos archivos (NO subir PDFs ni Excels con datos reales).
2. Entra en https://share.streamlit.io con tu cuenta de GitHub y pulsa "Create app".
3. Elige tu repositorio, rama main y archivo principal app.py.
4. En "Advanced settings": Python 3.12 y, en Secrets, una contraseña:  PASSWORD = "tu_contraseña"
5. Pulsa "Deploy". Cuando termine te da el enlace.

Para actualizar: cambia procesar_visitas.py o app.py en GitHub y la aplicación se vuelve a publicar sola.
